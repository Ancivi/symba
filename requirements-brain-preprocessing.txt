# Environment for notebooks/brain_neuropixel_preprocessing.ipynb only (Python 3.11).
#
# Install it with ./setup_brain_preprocessing_env.sh, not with `pip install -r`: the
# pynwb/hdmf versions below deliberately override what allensdk and ndx-events ask for,
# so pip's resolver refuses to install everything at once. The script installs the
# packages in an order that works (its header also lists the conda equivalent).
#
# Why these pins:
#   - pynwb/hdmf: the Allen Institute's .nwb files use an old NWB schema that recent
#     pynwb/hdmf versions cannot read; AllenSDK treats a failed read as a corrupt file
#     and downloads it again (see data/README.md). These versions read the files.
#   - numpy/scipy: allensdk requires numpy<1.24 and scipy<1.11, which is why this
#     notebook cannot share the environment of the rest of the project.
#   - scikit-learn<1.4: needed by `import symba`; newer versions require numpy>=1.24.
#   - Python 3.11: allensdk dependencies such as `tables` have no prebuilt wheels for
#     older Python versions on macOS arm64.
#   - xgi is not included (it requires scipy>=1.15, incompatible with allensdk); the
#     notebook does not use it.
